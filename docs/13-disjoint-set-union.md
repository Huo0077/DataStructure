## 13.1 动态连通性问题与等价关系

在许多现实场景中，我们需要维护一个动态的“朋友圈”或“连通网络”：
- **操作 1：`union(p, q)`** —— 在网络中连接两个实体 \(p\) 和 \(q\)（建立关系）；
- **操作 2：`connected(p, q)` / `find(p)`** —— 查询实体 \(p\) 和 \(q\) 是否处于同一连通分支中。

在数学上，连通性是一种**等价关系（Equivalence Relation）**，满足：
1. **自反性**：\(p\) 与自身连通；
2. **对称性**：若 \(p\) 与 \(q\) 连通，则 \(q\) 与 \(p\) 连通；
3. **传递性**：若 \(p\) 与 \(q\) 连通，且 \(q\) 与 \(r\) 连通，则 \(p\) 与 \(r\) 必然连通。

## 13.2 并查集的演进之路：从 Quick-Find 到 Quick-Union

```text
【演进 1：Quick-Find 方案】
- 物理存储: 数组 id[n]，每个位置直接存所属集合的唯一 ID (如帮派编号)
- Find(p): return id[p];  ───> O(1) 极速
- Union(p, q): 必须遍历整个数组，将所有等于 id[p] 的元素改为 id[q] ───> O(n) 缓慢！
- 瓶颈: 连续 N 次合并需要 O(N²)，面对海量数据直接瘫痪。

【演进 2：Quick-Union 方案】
- 物理存储: 树形森林，每个节点只记录自己的父节点 parent[p]
- Find(p): 顺着 parent 指针一路向上爬到根节点 ───> O(树高)
- Union(p, q): 找到 p 和 q 的根节点 rootP 和 rootQ，直接令 parent[rootP] = rootQ ───> O(树高)
- 瓶颈: 若无控制，树可能退化为瘦长的单链表，单次操作依然退化为 O(n)！
```

## 13.3 极简工程美学：单数组双重语义设计（parent 数组编码）

在通用实现中，很多人会开两个数组：`int parent[N]` 和 `int size[N]`。然而，著名算法学家 Mark Allen Weiss 展示了一种**令人拍案叫绝的单数组双重编码方案**：

```text
               ┌────────────────────────────────────────────────────────┐
               │              parent 数组的单一物理存储                │
               └────────────────────────────────────────────────────────┘
                    │                                        │
                    ▼                                        ▼
    【若 parent[i] >= 0】                     【若 parent[i] < 0】
    表示节点 i 不是根，其值为【父节点下标】     表示节点 i 本身就是【树根】！
                                               且 |parent[i]| 恰好是该集合的【元素总数】！
```

```cpp
class DisjointSet {
private:
    std::vector<int> parent; // 初始时所有元素均为 -1 (每个节点自成一棵大小为 1 的树)

public:
    DisjointSet(int n) : parent(n, -1) {}

    // 判断是否为根
    bool isRoot(int x) const { return parent[x] < 0; }
    
    // 获取根所在集合的大小
    int getSetSize(int root) const { return -parent[root]; }
};
```
> **工程之美**：利用负数符号位消除冗余数组，内存开销直接减半，且绝无两数组不同步的隐患！

## 13.4 两大核心优化与双剑合璧

<a id="c13-13-4-1"></a>
### 13.4.1 启发式合并：按大小（Size）或按秩（Rank）合并的树高对数证明

**核心准则**：合并两棵树时，**永远将较小的树挂到较大的树的根节点之下**（矮树挂在大树下）。

```text
    大树 (size = 5)       小树 (size = 2)                   合并后
         Root1                 Root2                        Root1 (size = 7)
        /  │  \                /                           /  │  \   \
       o   o   o              o                          o   o   o   Root2
                                                                      /
                                                                     o
（小树挂在大树下，小树中所有节点的深度仅增加 1，而大树所有节点的深度完全不受影响！）
```

#### 树高上界定理证明：
**定理**：采用按大小（或按秩）合并，包含 \(n\) 个节点的树，其高度 \(h \le \lfloor \log_2 n \rfloor + 1\)。  
*证明*：  
考虑任意一个节点 \(x\)。只有当包含 \(x\) 的树被合并到一棵**规模至少与它自身一样大**的树之下时，\(x\) 的深度才会增加 1。  
因此，\(x\) 的深度每增加 1，它所属树的节点总规模**至少翻倍（\(\times 2\)）**！  
因为全树总节点数至多为 \(n\)，规模至多翻倍 \(\log_2 n\) 次。  
故任何节点的深度绝对不会超过 \(\lfloor \log_2 n \rfloor + 1\)！查找与合并在最坏情况下稳稳锁定在 \(O(\log n)\)！

<a id="c13-13-4-2"></a>
### 13.4.2 路径压缩（Path Compression）：读操作就地扁平化

按大小合并已经将树高限制在 \(O(\log n)\)，但计算机科学家们更进一步：**为什么每次 `find` 爬树之后，不顺手把沿途的所有节点直接挂到根节点上？**

```text
【路径压缩前】                       【执行 find(1) 路径压缩后】
        4 (根)                                   4 (根)
        │                                      / │ \
        3                                     1  2  3  (整棵树瞬间被极致扁平化!)
        │
        2
        │
        1 (查找目标)
```

### 极简的一行递归实现：
```cpp
int find(int x) {
    if (parent[x] < 0) return x; // 找到了根
    return parent[x] = find(parent[x]); // 递归寻根，并就地更新父指针！
}
```

## 13.5 复杂度奇迹：阿克曼函数与反阿克曼函数 α(n)

当**按大小合并**与**路径压缩**同时使用时，Robert Tarjan 于 1975 年证明了并查集的单次操作均摊时间复杂度为：
\[
T(n) = O(\alpha(n))
\]
其中 \(\alpha(n)\) 为**反阿克曼函数（Inverse Ackermann Function）**。

### 阿克曼函数的增长有多恐怖？
阿克曼函数 \(A(m, n)\) 的定义如下：
\[
A(0, n) = n + 1
\]
\[
A(m, 0) = A(m - 1, 1)
\]
\[
A(m, n) = A(m - 1, A(m, n - 1))
\]
- \(A(1, n) = n + 2\)
- \(A(2, n) = 2n + 3\)
- \(A(3, n) = 2^{n+3} - 3\)
- \(A(4, 1) = 2^{16} - 3 = 65,533\)
- \(A(4, 2) = 2^{65536} - 3\) —— 这个数字的十进制位数超过 19,700 位，远超全宇宙原子总数（\(\approx 10^{80}\)）！

### 反阿克曼函数的物理直观：
\(\alpha(n)\) 定义为满足 \(A(k, k) \ge n\) 的最小整数 \(k\)：
- 当 \(n \le 65,536\) 时，\(\alpha(n) \le 3\)；
- 当 \(n \le 2^{65536}\) 时，\(\alpha(n) \le 4\)；
- **对于人类现实世界中能接触到的任何宇宙级天文数字，\(\alpha(n) \le 4\)**！  
因此，在一切工程实践中，我们完全可以自信地将并查集的操作视为 **\(O(1)\) 常数时间**！

## 13.6 高阶拓展：带权并查集与可撤销并查集（Rollback DSU）

### 1. 带权并查集（Weighted DSU）
在节点与父节点之间的边上赋予权值（代表两者间的相对关系，如相对距离、模关系）。  
在路径压缩时，根据群论或向量加法同步更新权值：`weight[x] += weight[oldParent]`。  
**经典应用**：POJ 1182《食物链》（A 吃 B、B 吃 C、C 吃 A 的模 3 关系判定）。

### 2. 可撤销并查集（Rollback DSU）
在某些分治算法（如动态图连通性、线段树分治）中，需要支持“撤销上一次 union 操作”。  
- **关键设计**：**放弃路径压缩**（因为路径压缩会破坏原有的树形拓扑，无法回退），**仅使用按大小合并**（维持树高 \(O(\log n)\)）；
- 维护一个历史变更栈 `std::stack<Operation>`，每次回退只需恢复修改过的两个数组槽位即可。

## 本章小结

1. **等价关系的极简抽象**：并查集将动态连通性简化为双亲指针森林。
2. **负数复用编码**：用负数一石二鸟兼顾根标志与集合大小，是 C++ 内存布局的精妙范式。
3. **双重优化实现理论极限**：按大小合并控制树高上界，路径压缩就地摊平分支。
4. **反阿克曼函数的工程意义**：这是理论计算机科学中极其罕见但确定性的“非严格常数的实用常数”。
